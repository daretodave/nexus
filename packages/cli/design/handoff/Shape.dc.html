4How should agents split the work?
By size · small chunks stay in this session, medium ones delegate, large ones fan out. Cost follows the work.
Sub-agents · each is briefed in its own context, so the main one stays clear. You pay for every briefing.
Workflows · several agents work one chunk and check each other. The most thorough, and the most tokens.
