Space, radius, elevation, motion

A 4px grid underneath everything, soft radii, depth shown as light rather than shadow, and four named motions that breathe and drift but never bounce.

Motion · four named curves

snap140ms
cubic-bezier(.2, 0, 0, 1)

Direct response: hover, press, toggles, checkbox ticks. Starts at once and stops dead, no tail.

settle520ms · pull 900ms
cubic-bezier(.16, 1, .3, 1)

Arrivals: cards, toasts, a parked question sliding into its tray. Quick out, long soft landing, no overshoot.

breathe5.2s loop
cubic-bezier(.37, 0, .63, 1)

Inhale and exhale, alternate: orb halos, the phase bead, a pending tug leaning toward you by 6px.

drift18 to 40s
cubic-bezier(.45, .05, .55, .95)

Ambient only: the aurora, the shipped river, stars. Slow enough that you never notice it start.

Demo dots run every curve at 2.4s so the shape is visible. Production durations are the ones in each header.

Rules and reduced-motion fallbacks

  • 1Nothing overshoots. No spring, no bounce, no elastic.
  • 2Only a question moves toward you. Everything else moves sideways, downward or in place.
  • 3Hush. While a question is pending, the aurora and river pause, halos slow to half speed and filament flow dims.
  • 4Ambient loops are 5s or slower, so a 40-minute glance never catches a flicker.
  • 5Entrances start visible. Nothing animates in from zero opacity, so a frozen frame or an export never hides content.
