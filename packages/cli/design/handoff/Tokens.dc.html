nexus design system · 05 handoff

Tokens as CSS custom properties

Everything on this canvas reads from one stylesheet, project/nexus.css. Night is the default; dawn overrides only what changes. Components never use a raw hex, only the semantic layer.

tokens · component classes · motion · reduced motion
Use
<!-- in <head>, after support.js -->
<link rel="stylesheet" href="./nexus.css">
<!-- theme on the root; it nests, so one board can show both -->
<div class="nx" data-theme="dark"> … </div>
Naming
--ink-* the one neutral scale --st-* agent and session states
--aurora-* the one accent --sess-* session identity
--s-* --r-* space, radius on a 4px grid --e-* elevation as light
--ease-* snap settle breathe drift --dur-* durations
