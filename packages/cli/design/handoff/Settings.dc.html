Owner mode

Only here because this checkout has a .owner file. On anyone else's checkout this section does not exist.

On: chunks land on main as they close. No pull requests and no package step. Each chunk drops into the shipped river as a commit, and the session track ends at Questions.Off: this checkout works like a contributor.   • The top bar shows a solid owner chip with a lock while it is on.

Run mode

How sessions split a chunk between agents. Changes apply from the next chunk; a chunk mid-build keeps its mode.

By size · small chunks stay in this session, medium ones delegate, large ones fan out. Cost follows the work.
Sub-agents · each is briefed in its own context, so the main one stays clear. You pay for every briefing.
Workflows · several agents work one chunk and check each other. The most thorough, and the most tokens.
