Rules for terminal surfaces
  • 1Line height is locked at 1.2 so vertical strokes overlap the line box instead of leaving hairline gaps.
  • 2Each line is its own row element; spacing lives inside text, never between tags.
  • 3State and phase glyphs sit in a fixed 1ch cell, so a missing glyph can never shift a column.
  • 4Agent states and chunk states use different families: rings and marks for agents, moon phases for chunks.
  • 5Heavy lines are reserved for the one thing that needs you; everything else is light.
