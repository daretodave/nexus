## Decisions
- **D?plugin-vendor-prompts** · 2026-11-20 · The plugin's three commands (`plugin/commands/{adopt,upgrade,doctor}.md`, generated by `scripts/build-plugin.mjs`) resolve their wrapped text through `${CLAUDE_PLUGIN_ROOT}/vendor/prompts/<name>.md`, a byte-for-byte vendored copy of `prompts/{adopt,upgrade,doctor}.md`; `doctor`'s script is vendored the same way at `${CLAUDE_PLUGIN_ROOT}/vendor/scripts/plugin-doctor.mjs`. *Why:* an installed plugin has no sibling `../nexus` checkout to read canonical paths from, so it needs the same offline-snapshot discipline `plugin/vendor/templates/` already uses.
