# Glossary

<PROJECT>'s words, one line each, rewritten in place to stay
true. A term the code, the specs and the UI use the same way.

- **spec**: one initiative in `plan/`, numbered for life; it
  ends in chunks and is deleted once they are built.
- **chunk**: one session-sized slice of a spec (`NN.k`, size
  S, M or L), closing one or more acceptance IDs.
- **A-ID**: an acceptance criterion's stable id (`A3`), never
  renumbered.
- **footgun**: a trap in how the project is built, with the
  rule (or automation) that prevents it.
